# 🏎️ BMW ASCII Art Showcase

โปรเจกต์แสดงผลรูปรถ BMW ในรูปแบบ ASCII Art โดยใช้ภาษา Python สำหรับนักพัฒนาที่ต้องการเพิ่มลูกเล่นให้กับ Terminal หรือหน้าจอ Command Line

## 📝 รายละเอียด
โปรเจกต์นี้สร้างขึ้นเพื่อแสดงศักยภาพของศิลปะจากตัวอักษร (ASCII Art) โดยเน้นไปที่รถยนต์แบรนด์ BMW ซึ่งเป็นสัญลักษณ์ของความพรีเมียมและนวัตกรรม

## 🚀 ฟีเจอร์
- **Visual Fidelity**: รูปรถที่มีความสมมาตรและรายละเอียดครบถ้วน
- **Error-Free Rendering**: ใช้เทคนิค `r'''` (Raw String) เพื่อให้การแสดงผลแม่นยำ 100%
- **Interactive UI**: มีระบบจำลองการโหลดข้อมูลก่อนแสดงผล
